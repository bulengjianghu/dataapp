# 第三阶段需求拆分（基础审批）

## 1. 阶段目标与范围（二维表）
| 维度 | 内容 | 说明 |
|---|---|---|
| 阶段目标 | 为填报数据增加基础审批闭环 | 覆盖提交、审批、驳回等核心流转 |
| 面向角色 | 填报人员、审批人员、业务管理员 | 管理员配置流程，审批人员处理任务 |
| 业务边界 | 支持串行/并行基础流程 | 暂不支持复杂流程编排与会签加签 |
| 成功标准 | 单据状态可追踪，审批结果可审计 | 超时与异常有明确处理策略 |

## 2. 功能需求矩阵（二维表）
| 模块 | 子功能 | 需求描述 | 验收标准 | 优先级 |
|---|---|---|---|---|
| 流程配置 | 审批流定义 | 支持节点、顺序、审批人配置 | 发布后可用于新提交单据 | P0 |
| 流程配置 | 条件分支（基础） | 按金额/类型等条件走不同分支 | 命中分支与配置一致 | P1 |
| 审批执行 | 提交与发起 | 填报提交后自动创建审批实例 | 实例与单据一一对应 | P0 |
| 审批执行 | 审批动作 | 同意、驳回、退回上一步、转交 | 状态变更可追踪 | P0 |
| 审批执行 | 待办中心 | 我的待办、已办、抄送列表 | 可按状态与时间筛选 | P0 |
| 审批执行 | 审批意见 | 支持意见、附件、操作时间记录 | 审批历史可完整回放 | P0 |
| 通知提醒 | 消息提醒 | 待办、驳回、通过消息通知 | 关键节点消息不丢失 | P1 |
| 审计追踪 | 流程日志 | 记录节点流转与操作者 | 支持按单据导出流程轨迹 | P0 |

## 3. 状态流转定义（二维表）
| 当前状态 | 触发动作 | 下一状态 | 备注 |
|---|---|---|---|
| 草稿 | 提交 | 审批中 | 创建审批实例 |
| 审批中 | 审批通过（非末节点） | 审批中 | 流转至下一节点 |
| 审批中 | 审批通过（末节点） | 已通过 | 流程结束 |
| 审批中 | 驳回 | 已驳回 | 返回填报人处理 |
| 已驳回 | 重新提交 | 审批中 | 使用最新流程版本策略待定 |
| 审批中 | 撤回（限定条件） | 已撤回 | 仅首节点未处理前可撤回 |

## 4. 风险与对策（二维表）
| 风险 | 影响 | 对策 |
|---|---|---|
| 审批人与组织关系变化频繁 | 流程中断 | 支持审批人兜底与代理机制 |
| 条件分支配置错误 | 错误流转 | 上线前增加流程仿真测试 |
| 消息延迟 | 任务处理不及时 | 增加站内信与重试策略 |
