# 基础报表需求拆分

## 1. 阶段目标与范围（二维表）
| 维度 | 内容 | 说明 |
|---|---|---|
| 阶段目标 | 提供基础报表分析能力 | 支持常用统计与看板展示 |
| 面向角色 | 业务管理员、分析人员 | 按权限查看数据 |
| 业务边界 | 仅基础图表与筛选 | 暂不包含高级钻取与智能分析 |

## 2. 功能需求矩阵（二维表）
| 模块 | 子功能 | 需求描述 | 优先级 |
|---|---|---|---|
| 报表配置 | 图表组件 | 表格、柱状图、折线图、饼图 | P0 |
| 报表配置 | 数据筛选 | 时间、状态、关键字段筛选 | P0 |
| 数据权限 | 可见范围控制 | 按角色/部门限制数据可见性 | P0 |
| 报表输出 | 导出 | 支持基础导出（Excel/PDF） | P1 |
