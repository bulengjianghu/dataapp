# 栅格与水平布局实现方案

## 1. 设计目标（二维表）
| 目标 | 说明 |
|---|---|
| 水平布局 | 支持组件在同一行横向排布，满足表单紧凑展示 |
| 栅格统一 | 编辑态与填报态使用同一套12栅格规则，避免展示不一致 |
| 容器隔离 | 分组容器内独立计算栅格，不影响容器外布局 |
| 响应式适配 | 移动端可降级为单列，保证可填写性 |

## 2. 栅格模型（二维表）
| 项 | 规则 | 示例 |
|---|---|---|
| 栅格总列数 | 固定12列 | `grid-template-columns: repeat(12, 1fr)` |
| 字段宽度 | 字段配置 `layout.span`，取值1-12 | `span=6` 表示占半行 |
| 换行规则 | 同一行累计span超过12自动换行 | `6+4`可同一行，`6+7`换行 |
| 满行规则 | `span=12`独占一行 | 文本域、附件常用 |
| 容器规则 | 容器内独立按12列计算 | 容器A内字段不与容器B混排 |
| 容错策略 | 非法span自动归一到1-12 | `0 -> 1`，`15 -> 12` |

## 3. 水平布局实现机制（二维表）
| 层级 | 实现方式 | 说明 |
|---|---|---|
| 编辑器画布 | CSS Grid横向布局 | 拖拽排序后根据`span`实时重排 |
| 分组容器 | 容器作为独立Grid上下文 | 容器内字段横向排布、容器间纵向排布 |
| 填报渲染 | 复用同一渲染协议 | `schema.layout.span`直接驱动渲染 |
| 预览页面 | 与填报页复用布局引擎 | 保障所见即所得 |

## 4. Schema约定（二维表）
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `layout.span` | number | 是 | 栅格宽度（1-12） |
| `layout.order` | number | 否 | 同层级排序权重 |
| `layout.offset` | number | 否 | 左侧偏移列数（可选，默认0） |
| `containerKey` | string | 否 | 所属容器标识；空表示顶层字段 |

示例：
```json
{
  "fieldKey": "amount",
  "label": "金额",
  "component": "number",
  "layout": { "span": 6, "order": 20 },
  "containerKey": "base_info"
}
```

## 5. 前端渲染建议（二维表）
| 方案 | 写法 | 优点 |
|---|---|---|
| CSS Grid（推荐） | 字段项设置 `grid-column: span n` | 实现简单、自动换行、与12栅格天然匹配 |
| Flex + 手工分行 | 先按span分组再渲染行 | 可控性高，但实现复杂 |

推荐样式：
```css
.form-grid {
  display: grid;
  grid-template-columns: repeat(12, minmax(0, 1fr));
  gap: 12px;
}

.form-grid-item[data-span="6"] { grid-column: span 6; }
.form-grid-item[data-span="12"] { grid-column: span 12; }
```

## 6. 编辑器交互规则（二维表）
| 场景 | 规则 | 用户反馈 |
|---|---|---|
| 调整字段宽度 | 属性面板选择宽度（25/33/50/100）映射到 `3/4/6/12` | 画布实时重排 |
| 拖拽排序 | 按拖拽结果更新 `layout.order` | 放置后即时生效 |
| 拖入容器 | 字段写入 `containerKey` 并在容器内按order排序 | 容器高亮提示 |
| 移出容器 | 清空 `containerKey` 回到顶层 | 顶层区域高亮落点 |
| 非法宽度 | 自动回退到默认 `span=12` | 提示“宽度已重置” |

## 7. 响应式策略（二维表）
| 断点 | 策略 | 说明 |
|---|---|---|
| `>=1200px` | 使用配置`span` | 桌面端展示完整布局 |
| `768-1199px` | 对大字段优先保留，其他字段向12靠拢 | 平板端避免拥挤 |
| `<768px` | 强制 `span=12` 单列 | 移动端保证可填写与可读性 |

## 8. 与Store联动（二维表）
| Store字段 | 作用 | 触发点 |
|---|---|---|
| `formSchemaSlice.draftSchema.fields[].layout.span` | 驱动字段横向宽度 | 属性面板修改宽度 |
| `formSchemaSlice.draftSchema.fields[].layout.order` | 驱动排序 | 拖拽排序完成 |
| `formSchemaSlice.draftSchema.containers[]` | 驱动容器内独立布局 | 新增/编辑/删除容器 |

## 9. 校验与测试要点（二维表）
| 类别 | 用例 | 预期 |
|---|---|---|
| 栅格正确性 | 3个`span=4`字段同一行 | 正确横向显示，无换行 |
| 自动换行 | `span=8`后跟`span=6` | 第二个字段自动换行 |
| 容器隔离 | 容器内外字段混排 | 仅在各自上下文计算布局 |
| 响应式 | 移动端打开多列表单 | 自动单列展示 |
| 回归测试 | 预览与填报比对 | 布局一致 |
