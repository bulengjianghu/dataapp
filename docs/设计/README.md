# 设计文档索引

## 目录说明

本目录用于沉淀技术设计、架构约束、专题方案与关键取舍，作为研发实现和技术评审的主要依据。

推荐阅读顺序：

1. 先看全局设计文档，理解整体技术基线
2. 再进入对应阶段目录，阅读阶段主设计
3. 最后按需查看前端/后端专题设计

## 约束

- 本目录文档必须明确输入文档、设计目标、关键结论和取舍
- 需求范围以 `docs/需求` 为准，设计文档不应重新覆盖需求边界
- 同一阶段建议维护主设计文档和专题设计文档的引用关系
