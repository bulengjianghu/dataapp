# 编辑态运行态组件设计

## 1. 设计目标（二维表）
| 目标 | 说明 |
|---|---|
| 统一协议 | 编辑态与运行态都消费同一份 `Node/schema` 数据 |
| 职责分离 | 编辑器增强能力与业务渲染能力解耦 |
| 复用渲染 | 运行态渲染器可复用于预览、填报、发布后运行场景 |
| 降低污染 | 避免在单个组件内部堆积大量 `mode` 分支判断 |

## 2. 总体方案（二维表）
| 层次 | 作用 | 说明 |
|---|---|---|
| 协议层 | 统一节点协议 | 编辑态与运行态共享 `Node` 数据结构 |
| 运行态渲染器 | 纯业务渲染 | 只负责把节点渲染成真实 UI，不关心拖拽/高亮 |
| 编辑态包装器 | 编辑增强 | 在运行态组件外包裹拖拽、选中、高亮、删除等能力 |
| 页面级渲染器 | 组织整棵树 | 编辑页使用编辑态渲染器，运行页使用运行态渲染器 |

## 3. 推荐组件分层（二维表）
| 组件 | 类型 | 职责 |
|---|---|---|
| `RuntimeNodeRenderer` | 运行态内核 | 按节点类型渲染真实业务组件 |
| `EditorNodeWrapper` | 编辑态包装器 | 为普通节点增加选中、高亮、拖拽手柄、删除入口 |
| `ContainerEditorWrapper` | 编辑态容器包装器 | 为容器节点增加投放区、空态提示、容器操作栏 |
| `FormRuntimeRenderer` | 运行态页面渲染器 | 递归渲染整棵节点树 |
| `FormEditorRenderer` | 编辑态页面渲染器 | 递归渲染节点树，并为每个节点挂编辑增强层 |

## 4. 编辑态与运行态差异（二维表）
| 能力 | 编辑态 | 运行态 |
|---|---|---|
| 拖拽排序 | 支持 | 不支持 |
| 选中高亮 | 支持 | 不支持 |
| 删除确认 | 支持 | 不支持 |
| 空容器占位 | 支持 | 不支持 |
| 属性配置入口 | 支持 | 不支持 |
| 真实输入绑定 | 可弱化/禁用 | 支持 |
| 表单校验与提交 | 不负责 | 负责 |

## 5. 实现模式（二维表）
| 模式 | 说明 | 结论 |
|---|---|---|
| 单组件内 `mode` 分支 | 在一个组件里写大量 `if (mode === 'editor')` | 不推荐，逻辑污染严重 |
| 运行态组件 + 编辑态包装器 | 运行态纯渲染，编辑态在外层增强 | 推荐 |

## 6. 典型渲染关系（二维表）
| 场景 | 渲染关系 |
|---|---|
| 编辑态普通节点 | `EditorNodeWrapper(RuntimeNodeRenderer(node))` |
| 编辑态容器节点 | `ContainerEditorWrapper(RuntimeNodeRenderer(node))` |
| 运行态节点 | `RuntimeNodeRenderer(node)` |

示例：
```ts
function renderNode(node: Node, mode: 'editor' | 'runtime') {
  const content = <RuntimeNodeRenderer node={node} />;

  if (mode === 'editor') {
    if (node.type === 'container') {
      return (
        <ContainerEditorWrapper node={node}>
          {content}
        </ContainerEditorWrapper>
      );
    }

    return (
      <EditorNodeWrapper node={node}>
        {content}
      </EditorNodeWrapper>
    );
  }

  return content;
}
```

## 7. 为什么这样设计（二维表）
| 价值 | 说明 |
|---|---|
| 复用性 | 运行态组件可直接复用于预览/填报 |
| 可维护性 | 编辑器能力集中在 wrapper，不污染业务组件 |
| 可扩展性 | 新增组件时优先实现运行态，再补编辑态增强 |
| 测试清晰 | 运行态与编辑态可分别测试，边界清楚 |

## 8. 落地建议（二维表）
| 步骤 | 内容 | 产出 |
|---|---|---|
| Step 1 | 抽出 `RuntimeNodeRenderer` | 统一运行态渲染入口 |
| Step 2 | 实现 `EditorNodeWrapper` / `ContainerEditorWrapper` | 编辑器增强能力分层 |
| Step 3 | 页面级区分 `FormEditorRenderer` 与 `FormRuntimeRenderer` | 编辑页/运行页职责清晰 |
| Step 4 | 禁止在运行态组件中混入拖拽和删除逻辑 | 保持运行态纯净 |
