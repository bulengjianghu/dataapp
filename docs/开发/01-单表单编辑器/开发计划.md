## 3. 统一技术约束（技术栈、状态边界、组件边界）

### 3.1 技术栈

| 项 | 选型 |
|---|---|
| 前端框架 | React + TypeScript |
| UI 组件库 | Ant Design |
| 拖拽库 | dnd-kit |
| 状态管理 | Redux Toolkit |

### 3.2 状态边界

| 约束 | 说明 |
|---|---|
| 业务状态 | 进入 Redux（节点树、选中态、dirty、历史快照） |
| 瞬时 UI 状态 | 组件本地维护（如删除浮层显隐、锚点坐标） |
| 单一数据源 | 节点实体仅存在于 `nodesById` |
| 顺序来源 | 父节点 `childrenIds` 表达顺序与关系 |

### 3.3 组件边界

| 约束 | 说明 |
|---|---|
| 运行态内核 | `RuntimeNodeRenderer` 只负责业务渲染，不混入编辑能力 |
| 编辑态增强 | 通过 `EditorNodeWrapper`、`ContainerEditorWrapper` 增加选中、拖拽、删除能力；字段内容渲染由组件渲染器负责 |
| 预览态 | 复用运行态渲染协议，不挂编辑增强 |

## 4. 公共接口与类型契约

### 4.1 Node 契约

```ts
const PAGE_NODE_ID = 'page_root' as const;

type NodeType = 'page' | 'container' | 'field' | 'text';

type Node = {
  id: string;
  serverId: string | null;
  type: NodeType;
  parentId: string | null;
  childrenIds: string[];
  props: Record<string, any>;
  layout: {
    span?: number;
    order?: number;
  };
};
```

### 4.2 根节点与数据结构约束

| 约束 | 说明 |
|---|---|
| 根节点常量 | `PAGE_NODE_ID = 'page_root'` |
| 根节点规则 | 不可删除、不可拖动 |
| 数据模型 | `nodesById` 为唯一实体数据源 |
| 顺序模型 | 顶层与容器统一用 `childrenIds` 表达顺序 |
| 关系一致性 | `parentId` 与父节点 `childrenIds` 双向一致 |

### 4.3 核心 reducer 契约

| reducer | 职责 |
|---|---|
| `addNode` | 新增节点并插入目标父节点顺序 |
| `moveNode` | 同层/跨层移动节点并维护顺序 |
| `moveNodeToContainer` | 将节点移入容器指定位置 |
| `updateNodeProps` | 合并属性 patch，标记 dirty |
| `removeNodeCascade` | 递归删除节点及其子树 |
| `selectNode` | 设置当前选中节点 |
| `markDirty` | 更新脏状态 |
| `resetDraft` | 恢复草稿快照 |

### 4.4 核心 thunk 契约

| thunk | 职责 |
|---|---|
| `loadFormDraft` | 拉取草稿并初始化节点树 |
| `saveDraft` | 保存草稿 schema，更新脏状态 |
| `publishForm` | 发布前校验并执行发布 |
| `deleteSelectedNode` | 删除选中节点并触发级联删除逻辑 |

### 4.5 拖拽落点协议

| 项 | 约束 |
|---|---|
| droppable 类型 | `form-root`、`container` |
| 落点优先级 | 容器内部可投放区 > 容器外框 > 根画布 |
| 写入规则 | 顶层写入根节点 `childrenIds`；容器写入容器 `childrenIds` |
| 非法投放 | 禁止写入并给出反馈 |

### 4.6 组件渲染契约

| 项 | 约束 |
|---|---|
| 渲染注册表 | 通过 `componentRenderRegistry` 维护 `component -> renderer` 的映射 |
| 编辑态渲染 | 编辑态节点外壳与字段内容分层，字段内容必须按具体组件类型呈现 |
| 运行态渲染 | `RuntimeNodeRenderer` 直接消费 `props.component` 与通用 props 渲染真实组件 |
| 统一输入 | 渲染器统一消费 `label`、`required`、`placeholder`、`options`、`layout` |
| MVP 覆盖范围 | `input`、`textarea`、`number`、`date`、`radio`、`checkbox`、`select`、`upload`、`container` |

## 7. 验收标准（功能 + 性能）

### 7.1 功能验收

| 类别 | 验收标准 |
|---|---|
| 拖拽编排 | 支持顶层与容器内拖拽新增、排序、跨容器移动，顺序正确且持久化稳定 |
| 属性配置 | 选中不同节点展示对应配置项，修改后画布与预览实时一致 |
| 组件渲染 | 单行文本、多行文本、数字、日期、单选、多选、下拉、附件在编辑态预览中具备差异化渲染 |
| 删除行为 | 非模态删除确认可用；容器删除触发级联删除并正确清理选中态 |
| 保存发布 | 草稿保存可用，`serverId` 回填正确；发布前校验可阻断非法配置 |
| 预览一致性 | 预览态与运行态渲染协议一致，不包含编辑增强能力 |

### 7.2 性能验收

| 指标 | 目标值 | 场景 |
|---|---|---|
| 编辑器打开时间 | < 2s | 30 字段表单 |
| 属性面板切换响应 | < 300ms | 连续切换字段 |
| 草稿保存响应 | < 1s | 常规网络单次保存 |

## 9. 风险与缓解

| 风险 | 触发信号 | 影响 | 缓解策略 | 兜底 |
|---|---|---|---|---|
| 拖拽与节点树同步复杂 | 跨容器移动后结构错乱 | 排序异常、数据不一致 | 严格按 `parentId + childrenIds` 双写一致校验 | 增加结构自检与回滚 |
| 属性面板动态渲染不稳定 | 切换组件配置项错乱 | 配置不可编辑或错误写回 | 注册表 schema 约束 + resolver 单测 | 回退到基础配置项集 |
| 组件渲染协议不统一 | 编辑态和预览态展示不一致 | 用户感知与真实效果偏差 | 建立 `componentRenderRegistry + RuntimeNodeRenderer` 共用协议 | 预览页回退到基础只读渲染 |
| 本地 `id` 与 `serverId` 回填错配 | 保存后映射异常 | 后续操作定位错误 | 使用 `clientId + serverId` 映射回填，不替换本地 `id` | 保存失败重试与日志追踪 |
| 历史快照过大 | undo/redo 卡顿 | 编辑体验下降 | MVP 仅记录结构变更快照 | 限制历史栈长度 |
| 性能退化 | 大表单切换卡顿 | 试点不可用 | 局部渲染、选择器优化、慢路径梳理 | 先降级部分非核心交互 |
