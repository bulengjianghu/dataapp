# 需求文档索引

## 目录说明

本目录用于描述产品目标、阶段范围、业务能力、验收标准与边界约束，不负责展开技术实现细节。

推荐阅读顺序：

1. 先看总览文档，理解整体阶段划分
2. 再看对应阶段目录下的 `README.md`
3. 最后阅读阶段主需求和专题需求

- 本目录文档以“做什么、为什么做、如何验收”为主
- 技术选型、表结构、接口、模块拆分应下沉到 `docs/设计`
- 新增阶段主需求文档时，优先使用统一命名 `阶段需求.md`
