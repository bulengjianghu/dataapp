# 第二阶段需求拆分（关联表与业务规则）

## 1. 阶段目标与范围（二维表）
| 维度 | 内容 | 说明 |
|---|---|---|
| 阶段目标 | 在单表基础上支持关联表与核心业务规则 | 实现多实体数据协同填报 |
| 面向角色 | 业务管理员、填报人员 | 管理员维护关联关系与规则 |
| 业务边界 | 支持主表+子表/关联表 | 审批与打印仍不在本阶段 |
| 成功标准 | 关联数据可维护且规则可稳定执行 | 提交时规则结果可追踪 |

## 2. 功能需求矩阵（二维表）
| 模块 | 子功能 | 需求描述 | 验收标准 | 优先级 |
|---|---|---|---|---|
| 关联表 | 主子表结构 | 支持一对多明细表配置 | 明细可增删改且随主单保存 | P0 |
| 关联表 | 跨表引用 | 子表字段可引用主表关键字段 | 引用值自动同步 | P0 |
| 关联表 | 关联选择 | 从关联数据源选择并回填字段 | 回填映射可配置 | P0 |
| 业务规则 | 字段联动 | 基于条件控制显示/只读/必填 | 条件变化后即时生效 | P0 |
| 业务规则 | 计算规则 | 支持合计、差值、表达式计算 | 计算结果可参与校验 | P0 |
| 业务规则 | 唯一性与重复校验 | 跨记录重复校验（指定字段组合） | 提交时准确拦截重复 | P0 |
| 业务规则 | 生命周期规则 | 新建/编辑/提交阶段触发不同规则 | 规则触发时机可配置 | P1 |
| 数据能力 | 批量导入 | 支持模板导入主表+明细数据 | 导入错误可定位行列 | P1 |
| 数据能力 | 版本兼容 | 表单结构升级兼容历史数据 | 历史记录可正常查看 | P1 |

## 3. 规则治理与运维（二维表）
| 项目 | 需求 | 验收标准 |
|---|---|---|
| 规则可观测性 | 记录规则命中与失败日志 | 可按规则ID检索执行结果 |
| 规则冲突检测 | 发布前检测互斥/循环依赖 | 阻止冲突规则上线 |
| 性能保障 | 大表单规则执行时延可控 | 常规场景规则执行 < 300ms |

## 4. 风险与对策（二维表）
| 风险 | 影响 | 对策 |
|---|---|---|
| 规则复杂度快速上升 | 配置与维护成本高 | 制定规则分层和命名规范 |
| 跨表一致性问题 | 数据错误与对账困难 | 增加事务与数据校验机制 |
| 导入质量波动 | 上线初期错误率高 | 提供模板校验与预检查 |
