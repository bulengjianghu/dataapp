## 1. 目标与范围（二维表）
| 维度 | 内容 | 说明 |
|---|---|---|
| 目标 | 提供可配置、可发布的单表表单编辑器 | 支持业务管理员零代码搭建表单 |
| 范围 | 组件管理、布局编排、属性配置、交互体验、发布管理 | 对应第一阶段单表能力 |
| 不含范围 | 关联表、复杂规则引擎、审批流程、打印模板 | 放到后续阶段 |
| 成功标准 | 管理员可独立完成“新建-配置-预览-发布”闭环 | 配置后填报端可稳定渲染 |

## 2. 组件体系（二维表）
| 组件类型 | 组件名称 | 配置项 | 校验能力 | 是否P0 |
|---|---|---|---|---|
| 基础输入 | 单行文本 | 标题、占位提示、默认值、最大长度、只读、必填 | 必填、长度、正则 | 是 |
| 基础输入 | 多行文本 | 标题、默认值、行数、最大长度、只读、必填 | 必填、长度 | 是 |
| 数值输入 | 数字 | 标题、默认值、小数位、最小值、最大值、步长 | 范围、精度 | 是 |
| 时间输入 | 日期 | 标题、默认值、格式、可选范围 | 必填、范围 | 是 |
| 选项输入 | 单选 | 标题、选项列表、默认选中、展示方式 | 必填、合法选项 | 是 |
| 选项输入 | 多选 | 标题、选项列表、默认值、最多选择数 | 必填、数量限制 | 是 |
| 选项输入 | 下拉选择 | 标题、选项、是否可搜索、默认值 | 必填、合法选项 | 是 |
| 文件输入 | 附件上传 | 标题、文件类型、大小限制、数量限制 | 类型、大小、数量 | 是 |
| 展示组件 | 分组标题/说明文本 | 标题文本、样式等级、说明文案 | 无 | 否（P1可做） |

## 3. 布局设计需求（二维表）
| 布局能力 | 需求描述 | 配置方式 | 验收标准 | 优先级 |
|---|---|---|---|---|
| 栅格布局 | 支持1列/2列布局切换 | 表单级配置 | 表单预览与填报端一致 | P0 |
| 字段排序 | 支持拖拽调整字段顺序 | 画布拖拽 | 保存后顺序稳定 | P0 |
| 分组布局 | 字段可按业务分组展示 | 分组容器+标题 | 分组内字段独立排序 | P1 |
| 字段宽度 | 支持半行/整行占位 | 字段级宽度属性 | 多终端自动换行不重叠 | P0 |
| 响应式适配 | PC与移动端自适应展示 | 系统内置规则 | 移动端字段可完整输入 | P0 |

## 4. 属性配置面板（二维表）
| 属性分类 | 具体属性 | 生效时机 | 默认策略 | 风险控制 |
|---|---|---|---|---|
| 基础属性 | 字段标识、字段标题、提示语 | 保存后立即生效 | 自动生成唯一标识 | 字段标识发布后禁止修改 |
| 交互属性 | 必填、只读、可见、默认值 | 预览和填报实时生效 | 默认“非必填+可编辑” | 非可见字段不参与前端提交 |
| 数据属性 | 数据类型、长度、小数位、枚举选项 | 提交时后端强校验 | 按组件类型预置 | 类型变更触发兼容性检查 |
| 校验属性 | 正则、范围、提示文案 | 提交前校验 | 默认通用错误文案 | 自定义文案长度限制 |
| 展示属性 | 占位文本、帮助信息、宽度 | 渲染时生效 | 使用组件默认模板 | 防止超长文本挤压布局 |

## 5. 编辑交互细节（二维表）
| 交互场景 | 触发方式 | 期望行为 | 异常反馈 |
|---|---|---|---|
| 拖拽新增组件 | 从左侧组件区拖入画布 | 在落点生成新字段并默认命名 | 落点非法时禁止放置并提示 |
| 选中组件编辑属性 | 点击画布字段 | 右侧面板展示字段属性 | 属性加载失败时提示重试 |
| 字段重命名 | 编辑字段标题 | 实时更新画布与配置树 | 重名时允许标题重复但标识唯一 |
| 字段删除 | 点击删除按钮二次确认 | 从画布移除并清理临时配置 | 已引用字段删除时提示风险 |
| 撤销/重做 | 工具栏操作 | 恢复到上一步/下一步状态 | 无可操作栈时按钮置灰 |
| 自动保存 | 间隔或关键动作后触发 | 后台保存草稿并提示“已保存” | 保存失败提示并允许手动重试 |
| 离开提醒 | 页面关闭/切换 | 未保存变更时弹窗确认 | 用户确认离开则放弃未保存内容 |

## 6. 校验与错误处理（二维表）
| 校验层级 | 校验内容 | 触发时机 | 失败处理 |
|---|---|---|---|
| 配置时校验 | 字段标识唯一、选项非空、范围合法 | 保存字段配置时 | 阻断保存并高亮问题项 |
| 发布前校验 | 必填字段完整、组件参数合法、无冲突配置 | 点击发布时 | 阻断发布并输出问题清单 |
| 渲染时校验 | 未识别组件类型、缺失配置项 | 打开预览/填报页面 | 回退默认渲染并记录日志 |
| 提交时校验 | 必填、格式、范围、附件限制 | 填报提交时 | 返回字段级错误信息 |

## 7. 版本与发布管理（二维表）
| 能力 | 需求说明 | 规则 |
|---|---|---|
| 草稿态 | 所有编辑先保存到草稿 | 草稿可反复修改，不影响线上版本 |
| 发布态 | 发布后生成版本号（如 v1, v2） | 同一时间仅一个启用版本 |
| 停用 | 可停用当前版本 | 停用后填报端不可新建 |
| 复制版本 | 允许从历史版本复制为新草稿 | 用于快速迭代 |
| 变更记录 | 保存字段新增/修改/删除日志 | 支持按版本查看差异摘要 |

## 8. 权限与审计（二维表）
| 权限对象 | 操作权限 | 约束 |
|---|---|---|
| 业务管理员 | 新建、编辑、发布、停用、删除草稿 | 仅限授权业务域内表单 |
| 填报人员 | 仅查看发布后的表单结构 | 不可访问编辑器 |
| 审计人员 | 查看配置变更日志 | 只读，不可修改 |

## 9. 性能与体验指标（二维表）
| 指标项 | 目标值 | 场景 |
|---|---|---|
| 画布初始化时间 | < 2s | 打开包含30字段以内表单 |
| 属性面板切换响应 | < 300ms | 连续切换不同字段 |
| 保存草稿响应 | < 1s | 常规网络下单次保存 |
| 发布操作响应 | < 3s | 触发发布并完成校验 |
| 预览渲染时间 | < 2s | 进入预览页 |
