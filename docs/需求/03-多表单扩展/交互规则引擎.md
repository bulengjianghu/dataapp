# 交互规则引擎

## 1. 目标与定位（二维表）
| 维度 | 内容 | 说明 |
|---|---|---|
| 文档目标 | 抽象一套统一的填报交互规则引擎 | 支撑关联选择、跨层回填、筛选、汇总、计算、联动等复杂业务 |
| 适用范围 | 主表、明细表、关联选择组件及其他基础字段组件 | 面向当前表单填报场景，可引用其他表单数据 |
| 核心思想 | 采用流程编排式执行模型，将交互拆分为“事件触发 + 规则链执行 + 组件操作” | 避免按单个业务场景硬编码 |
| 设计原则 | 原子化、可编排、可扩展、可观测、前后端一致 | 规则应可复用、可调试、可版本化 |
| 业务目标 | 支撑订单、库存、项目管理等真实场景中的填报交互部分 | 满足跨层回填、筛选约束、汇总派生等需求 |

## 2. 系统分层与职责边界（二维表）
| 层级 | 定位 | 负责内容 | 不负责内容 |
|---|---|---|---|
| 前端交互规则引擎 | 当前表单填报交互引擎 | 当前表单内的触发、联动、回填、筛选、汇总、交互反馈、提交前预校验 | 跨表单事务一致性、库存扣减、状态流转、幂等控制、补偿回滚 |
| 服务端事务规则引擎 | 跨表单业务事务执行引擎 | 跨单据写入、领域规则裁决、一致性、幂等性、锁定、回滚、补偿、最终校验 | 页面内即时交互、组件级展示控制 |

## 3. 当前能力边界说明（二维表）
| 边界项 | 说明 |
|---|---|
| 事务边界 | 当前引擎以“当前表单”为执行边界，当前表单可包含主表、明细表和关联选择上下文 |
| 外部数据引用 | 允许查询和引用其他表单的数据，用于候选项加载、字段回填、筛选、计算和展示 |
| 外部数据写入 | 不负责将当前操作直接写入其他表单或其他业务单据 |
| 结果生效方式 | 主要影响当前表单的页面状态、字段值、候选项、明细数据和提交前结果 |
| 最终一致性 | 提交后的跨表单一致性、幂等、资源锁定需由服务端事务规则引擎保证 |
| 能力定位 | 它不是“单字段联动器”，也不是“跨系统事务引擎”，而是“以当前表单为边界、采用流程编排式执行模型的交互规则引擎” |

## 4. 核心抽象（二维表）
| 概念 | 定义 | 作用 |
|---|---|---|
| 组件能力 | 每个组件声明自己可接受的操作类型 | 限制规则引擎对组件的可执行动作范围 |
| 触发器 | 某个事件发生时启动规则执行 | 解决“什么时候执行规则” |
| 规则 | 由一组执行单元按顺序组成的流程 | 解决“执行哪些步骤” |
| 执行单元 | 规则中的最小原子动作 | 负责查询、计算、判断、发命令、写上下文等 |
| 运行上下文 | 当前页面、记录、行、关联结果、用户等运行时信息 | 为规则执行提供统一输入 |
| 操作命令 | 引擎对组件或表单容器下发的标准化命令 | 解决“如何改变界面和数据” |
| 作用域 | 主表、明细表、当前行、关联源记录等上下文边界 | 解决跨层引用和回填边界控制 |

## 5. 设计原则（二维表）
| 原则 | 说明 |
|---|---|
| 原子化 | 将“查询列表”“设置选项”“更新字段值”“追加明细行”等拆成独立执行单元 |
| 声明式 | 规则配置描述“触发条件、执行链路、目标组件”，而非散落在业务代码中 |
| 流程编排式执行 | 每条规则由多个原子执行单元按顺序编排执行，规则引擎本质上是交互层的流程编排执行框架 |
| 组件自治 | 组件只声明“可接受哪些操作”，不感知具体业务规则 |
| 分层控制 | 触发器负责启动，执行单元负责逻辑，组件负责响应命令 |
| 可组合 | 一个业务场景由多个规则串联，而不是由一个大而全逻辑块完成 |
| 可观测 | 每次规则执行都应有日志、状态、错误和耗时记录 |
| 可降级 | 某个执行单元失败时，应定义中断、跳过、兜底等策略 |
| 边界清晰 | 当前引擎负责“用户如何完成当前表单填报”，服务端负责“业务结果如何最终生效” |

## 6. 组件能力模型（二维表）
| 组件类型 | 可接受操作类型 | 示例 |
|---|---|---|
| 通用组件 | 设置可见性、设置只读、设置必填、设置禁用、设置提示文案 | 文本、数字、日期、单选、多选等均支持 |
| 文本组件 | 更新值、清空值、追加文本 | 选中客户后更新联系人名称 |
| 数值组件 | 更新值、清空值、设置精度、设置范围 | 汇总金额后回写总额字段 |
| 下拉/关联选择组件 | 设置选项列表、更新值、清空值、设置筛选条件、设置展示字段 | 查询目标表后更新下拉候选项 |
| 明细表组件 | 追加行、插入行、删除行、覆写整表、更新指定行、更新指定列、设置列可见性、设置行级状态 | 从模板记录复制整张明细表 |
| 容器组件 | 设置可见性、展开/收起、切换只读态 | 按单据类型展示不同分组 |
| 提交按钮等动作组件 | 设置可点击性、设置提示、触发确认 | 校验未通过时禁止提交 |

## 7. 操作命令标准（二维表）
| 命令类别 | 命令名称 | 参数示例 | 说明 |
|---|---|---|---|
| 属性类 | `setVisible` | `target=fieldA, value=true` | 设置组件可见性 |
| 属性类 | `setReadonly` | `target=fieldA, value=false` | 设置组件是否只读 |
| 数据类 | `setValue` | `target=customerName, value=\"华东公司\"` | 更新字段值 |
| 数据类 | `clearValue` | `target=customerPhone` | 清空字段值 |
| 选项类 | `setOptions` | `target=productSelector, options=[...]` | 更新下拉或关联选择列表 |
| 选项类 | `setFilter` | `target=batchSelector, condition=...` | 更新组件内置筛选条件 |
| 明细类 | `appendRow` | `target=detailTable, row={...}` | 向明细表追加一行 |
| 明细类 | `updateRow` | `target=detailTable, rowKey=R1, patch={...}` | 更新指定明细行 |
| 明细类 | `replaceTable` | `target=detailTable, rows=[...]` | 覆写整张明细表 |
| 反馈类 | `showMessage` | `level=warning, text=\"无可选库存\"` | 向用户反馈规则执行结果 |

## 8. 触发器模型（二维表）
| 触发类型 | 触发时机 | 典型用途 |
|---|---|---|
| 页面生命周期 | 页面加载完成、表单初始化完成、草稿恢复完成 | 初始化默认值、加载关联选项、恢复联动状态 |
| 值变化 | 字段值改变、失焦、清空、切换选中项 | 联动、计算、刷新筛选条件 |
| 用户动作 | 点击关联选择、点击按钮、增加明细行、删除明细行 | 拉取外部数据、执行批量赋值、补齐默认值 |
| 明细行为 | 明细行新增、复制、删除、排序 | 同步更新汇总、继承主表上下文 |
| 提交流程 | 点击暂存、点击提交、提交前校验、提交成功后 | 阻断非法提交、执行最终汇总与校验 |
| 系统事件 | 接口返回、异步任务完成、权限状态变化 | 刷新组件状态、处理回调链路 |

## 9. 规则模型（二维表）
| 属性 | 说明 |
|---|---|
| 规则ID | 规则唯一标识，用于配置、日志、排错 |
| 规则名称 | 便于管理员识别的业务名称 |
| 触发器 | 哪个事件触发该规则 |
| 触发条件 | 规则执行前的前置判断，可为空 |
| 执行单元列表 | 按顺序执行的原子动作链 |
| 失败策略 | 中断、跳过、继续执行、降级兜底 |
| 生效范围 | 主表、明细表、当前行、全部行等 |
| 发布状态 | 草稿、启用、停用 |
| 版本信息 | 与表单版本绑定，保证回溯一致 |

## 10. 执行单元模型（二维表）
| 执行单元类型 | 作用 | 说明 |
|---|---|---|
| 查询类 | 查询表单数据、查询外部记录、查询当前上下文 | 用于获取后续操作需要的数据源 |
| 判断类 | 条件判断、空值判断、权限判断、分支选择 | 决定后续执行路径 |
| 转换类 | 字段映射、结构转换、过滤、排序、聚合 | 将查询结果转成组件可消费格式 |
| 操作类 | 给组件发送标准操作命令 | 如设置选项、更新值、追加行 |
| 写上下文类 | 将临时结果写入规则上下文缓存 | 便于后续执行单元复用 |
| 反馈类 | 给用户提示、给日志系统打点 | 用于增强交互可理解性 |

## 11. 运行上下文模型（二维表）
| 上下文类型 | 内容示例 | 用途 |
|---|---|---|
| 页面上下文 | 表单ID、版本ID、模式（新建/编辑/查看） | 确定规则运行环境 |
| 数据上下文 | 主表数据、明细表数据、当前行数据 | 支撑跨层回填、汇总和筛选 |
| 组件上下文 | 当前触发组件ID、组件类型、当前值、旧值 | 确定触发源和操作目标 |
| 关联上下文 | 已选关联记录、候选列表、来源表单 | 支撑关联选择类规则 |
| 用户上下文 | 用户ID、角色、组织、权限范围 | 支撑数据过滤和权限校验 |
| 临时上下文 | 规则前序执行单元输出结果 | 在同一规则链中传递中间结果 |

## 12. 规则执行链路（二维表）
| 步骤 | 说明 |
|---|---|
| 1. 捕获事件 | 页面或组件事件触发规则引擎 |
| 2. 匹配触发器 | 找到与当前事件匹配且处于启用状态的规则 |
| 3. 构建运行上下文 | 注入页面、组件、数据、用户等上下文 |
| 4. 校验前置条件 | 判断是否满足规则执行条件 |
| 5. 顺序执行单元 | 按规则中定义的顺序执行查询、转换、操作等单元 |
| 6. 发出组件命令 | 将标准命令下发给目标组件或容器 |
| 7. 更新表单状态 | 组件响应后更新页面状态树 |
| 8. 记录日志与结果 | 记录执行耗时、输入输出、异常信息 |

## 13. 关联选择场景的规则拆解（二维表）
| 场景 | 触发器 | 执行单元链 | 结果 |
|---|---|---|---|
| 打开关联选择 | 点击关联选择组件 | 查询目标表数据 -> 过滤/排序 -> 转换为候选项 -> `setOptions` | 组件展示最新候选列表 |
| 选择某条记录 | 关联选择值变更 | 读取已选记录 -> 字段映射 -> `setValue` 到目标字段 | 指定字段被回填 |
| 切换主表上下文后刷新候选项 | 主表字段值变更 | 读取主表上下文 -> 查询目标表 -> 应用筛选条件 -> `setOptions` | 候选项列表随上下文变化 |
| 清空关联选择 | 组件值清空 | 清空回填字段 -> 清空候选缓存 -> 更新组件状态 | 避免残留旧值 |

## 14. 典型业务模式抽象（二维表）
| 业务模式 | 规则链示例 | 适用场景 |
|---|---|---|
| 主表选择 -> 主表回填 | 查询记录 -> 字段映射 -> 更新主表字段 | 客户、供应商、项目选择 |
| 主表选择 -> 明细筛选 | 读取主表值 -> 生成筛选条件 -> 更新明细行组件过滤器 | 仓库约束批次、项目约束任务 |
| 明细行选择 -> 本行回填 | 查询记录 -> 字段映射 -> 更新当前行字段 | 商品带出规格、单价、单位 |
| 明细变更 -> 主表汇总 | 提取明细列 -> 聚合计算 -> 更新主表汇总字段 | 金额合计、数量合计、任务数 |
| 明细模板复制 | 查询模板记录 -> 转换为行数组 -> `replaceTable` | 订单模板、BOM明细带入 |
| 提交前整体验证 | 遍历主表和明细 -> 校验条件 -> 反馈错误或放行 | 库存不足、项目成员越权、金额异常 |

## 15. 跨层规则支撑方案（二维表）
| 能力 | 实现方式 | 示例 |
|---|---|---|
| 主表 -> 主表 | 主表字段触发规则，直接操作主表其他组件 | 选客户后回填联系人 |
| 主表 -> 明细表 | 主表事件触发后，向明细表组件发送筛选、默认值或批量更新命令 | 选仓库后刷新所有明细行批次范围 |
| 明细行 -> 本行 | 当前行事件触发后，仅更新当前行数据 | 选商品后回填本行规格和单价 |
| 明细表 -> 主表 | 明细增删改触发汇总规则，更新主表字段 | 订单总金额自动汇总 |
| 外部记录 -> 主表/明细 | 查询外部表单记录后做字段映射 | 选任务后回填负责人、计划工时 |

## 16. 前端架构建议（二维表）
| 模块 | 责任 |
|---|---|
| 规则注册中心 | 注册规则定义，按事件索引规则 |
| 规则运行时 | 接收触发事件、构建上下文、调度执行单元 |
| 组件能力注册表 | 管理每类组件支持的操作类型与参数约束 |
| 命令分发器 | 将标准命令分发给对应组件实例或表单容器 |
| 状态树 | 统一维护主表、明细表、组件状态和候选项缓存 |
| 日志与调试面板 | 展示规则执行链路、入参、出参、异常信息 |

## 17. 后端协同约束（二维表）
| 方向 | 约束 |
|---|---|
| 规则配置存储 | 规则需结构化保存，支持版本化、灰度、回滚 |
| 查询接口 | 执行单元依赖的目标表查询接口应支持字段选择、条件过滤、分页 |
| 提交校验 | 后端需在提交前重放关键规则，不能完全信任前端计算结果 |
| 事务规则承接 | 涉及跨表单写入、库存扣减、状态推进、资源锁定的逻辑，应转交服务端事务规则引擎执行 |
| 日志追踪 | 规则执行失败需返回规则ID、单元ID、异常信息 |
| 权限控制 | 规则查询外部数据时仍受数据权限约束 |

## 20. 支撑业务场景说明（二维表）
| 场景 | 规则引擎支撑方式 |
|---|---|
| 订单管理 | 客户选择、商品带出、价格刷新、金额汇总等填报交互可拆为规则链；订单提交后的库存占用、状态流转需由服务端事务规则承接 |
| 库存管理 | 仓库上下文下沉、批次筛选、库存预校验、缺货标记可由触发器和执行单元组合实现；真实扣减和台账写入不在当前引擎边界内 |
| 项目管理 | 项目选择、任务筛选、成员回填、工时汇总、风险提示可通过跨层规则实现；预算冻结、资源冲突裁决等需由服务端规则承接 |

## 21. MVP建议范围（二维表）
| 范围 | 建议 |
|---|---|
| P0 必做 | 组件能力注册、事件触发、查询类单元、转换类单元、命令类单元、基础日志、关联选择回填 |
| P0 必做 | 主表 -> 主表、本行 -> 本行、主表 -> 明细筛选、明细 -> 主表汇总 |
| P0 边界 | 不包含跨表单事务写入、库存真实扣减、状态推进、幂等控制、补偿回滚 |
| P1 增强 | 条件分支、异步链路、失败兜底策略、调试面板、规则可视化流程编排 |
| P1 增强 | 批量命令、模板复制、复杂聚合、规则依赖分析 |

## 22. 风险与对策（二维表）
| 风险 | 影响 | 对策 |
|---|---|---|
| 规则过于自由 | 配置复杂、容易失控 | 用组件能力白名单和命令白名单限制操作边界 |
| 执行链过长 | 前端性能下降 | 支持局部触发、结果缓存、异步查询、防抖 |
| 前后端不一致 | 提交结果和页面显示不一致 | 后端重放关键规则，统一数据结构和表达式语义 |
| 事务边界误用 | 将跨表单一致性问题错误放入前端交互规则处理，导致数据不一致 | 明确交互规则引擎仅负责当前表单，跨表单事务统一下沉服务端事务规则引擎 |
| 调试困难 | 问题难定位 | 建立规则日志、执行轨迹、可视化调试面板 |
