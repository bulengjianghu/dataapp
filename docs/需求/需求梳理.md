# 需求梳理（表单编辑器 + 数据填报 + 可视化报表 + 单据打印）

## 一、需求总览（二维表）
| 维度 | 内容 | 说明/边界 | 优先级 |
|---|---|---|---|
| 项目目标 | 搭建统一的数据采集与业务出单平台 | 覆盖“设计表单→填报数据→分析报表→打印单据”闭环 | P0 |
| 目标收益 | 提升配置效率、减少人工录入错误、增强数据可视化能力 | 支持业务快速上线新单据/新流程 | P0 |
| 适用场景 | 巡检记录、业务申请、采购/出入库、服务工单、财务单据等 | 需支持多行业模板化扩展 | P0 |
| 终端形态 | Web 为主，移动端 H5/小程序适配（填报侧优先） | 管理端优先 PC；填报端兼容手机 | P1 |
| 部署模式 | SaaS/私有化可选 | 涉及数据隔离、租户管理与扩展能力 | P1 |

## 二、角色与职责（二维表）
| 角色 | 核心诉求 | 关键权限 | 典型操作 |
|---|---|---|---|
| 超级管理员 | 平台级配置与安全管控 | 租户管理、全局配置、审计查看 | 创建租户、配置权限模型 |
| 业务管理员 | 快速搭建业务表单与流程 | 表单设计、流程发布、模板管理 | 新建表单、发布版本、维护打印模板 |
| 填报人员 | 快速准确填报数据 | 新增/编辑/提交本人数据 | 按规则填报、上传附件、提交审批 |
| 审批人员 | 高效审核与追踪 | 审核、驳回、批注、转交 | 审批单据、查看历史记录 |
| 数据分析人员 | 构建报表并洞察趋势 | 报表配置、数据集访问 | 配置图表、设置筛选与钻取 |
| 审计人员 | 追溯变更与合规核查 | 只读访问、审计日志 | 查询操作记录与版本变更 |

## 三、功能需求矩阵（二维表）
| 功能域 | 子功能 | 详细需求 | 验收标准（示例） | 优先级 |
|---|---|---|---|---|
| 表单编辑器 | 字段组件库 | 支持文本、数值、日期、下拉、单选、多选、附件、明细表、关联选择 | 可拖拽生成表单并保存，明细表归属容器分类、关联选择归属选择分类 | P0 |
| 表单编辑器 | 布局设计 | 支持栅格布局、分组、分页、条件显示 | 不同分辨率下布局可用 | P1 |
| 表单编辑器 | 校验规则 | 必填、长度、格式、数值范围、跨字段校验、公式校验 | 提交时可阻断非法数据 | P0 |
| 表单编辑器 | 业务规则 | 默认值、联动、条件计算、字段权限（可见/只读） | 根据条件实时生效 | P0 |
| 表单编辑器 | 版本管理 | 草稿、发布、回滚、版本差异对比 | 历史版本可追溯与恢复 | P1 |
| 数据填报 | 录入体验 | 新建、暂存、续填、复制上一条、批量导入 | 普通用户可在 3 步内完成提交 | P0 |
| 数据填报 | 流程流转 | 提交、审批、驳回、撤回、转交、抄送 | 状态流转清晰可追踪 | P0 |
| 数据填报 | 数据质量 | 重复校验、异常提醒、提交前预校验 | 错误信息定位到字段级 | P0 |
| 数据填报 | 移动适配 | 手机端表单渲染、拍照上传、定位/签名（可选） | 关键操作在移动端可完成 | P1 |
| 可视化报表 | 图表能力 | 表格、柱状、折线、饼图、漏斗、趋势图、透视分析 | 图表配置无需开发 | P0 |
| 可视化报表 | 筛选与钻取 | 时间、组织、状态等筛选；下钻与联动 | 支持多维筛选与联动分析 | P0 |
| 可视化报表 | 数据权限 | 按角色/部门/数据范围控制可见性 | 不越权查看敏感数据 | P0 |
| 可视化报表 | 导出分享 | 导出 Excel/PDF、截图分享、定时推送（邮件/IM） | 可按权限导出与分享 | P1 |
| 单据打印 | 模板设计 | 所见即所得模板、固定区域、明细表、页眉页脚、条码/二维码 | 模板可视化配置并预览 | P0 |
| 单据打印 | 打印规则 | 按状态打印、批量打印、套打、分页控制 | 打印结果版式稳定 | P0 |
| 单据打印 | 输出能力 | PDF 生成、电子签章接口预留 | 生成速度和清晰度满足业务要求 | P1 |
| 系统管理 | 组织与权限 | 用户、角色、部门、岗位、数据权限、字段权限 | 权限变更实时生效 | P0 |
| 系统管理 | 审计与日志 | 登录日志、操作日志、数据变更日志 | 可按人/时间/对象追溯 | P0 |
| 系统集成 | 对外接口 | OpenAPI、Webhook、消息推送、主数据同步 | 与 ERP/CRM/OA 可对接 | P1 |

## 四、业务流程（二维表）
| 流程阶段 | 输入 | 核心动作 | 输出 |
|---|---|---|---|
| 1. 表单设计 | 业务需求、字段定义、审批规则 | 配置字段/校验/联动/流程并发布版本 | 可用表单模板 |
| 2. 数据填报 | 表单模板、用户身份 | 填写、暂存、提交、审批流转 | 结构化业务数据 |
| 3. 数据分析 | 历史填报数据、统计口径 | 配置数据集、图表、筛选器、看板 | 可视化分析报表 |
| 4. 单据输出 | 已审批数据、打印模板 | 渲染单据、打印或导出 PDF | 标准化业务单据 |
| 5. 审计追踪 | 用户行为、版本变更 | 查询日志、比对差异、合规留痕 | 审计报告与追溯结果 |

## 五、非功能需求（二维表）
| 类别 | 需求项 | 指标建议 | 优先级 |
|---|---|---|---|
| 性能 | 表单打开/提交响应 | 常规场景 < 2s；复杂场景 < 5s | P0 |
| 并发 | 多用户同时填报与查询 | 支持高峰并发与弹性扩展 | P1 |
| 可用性 | 系统稳定性 | 可用性目标 99.9%（按月） | P0 |
| 安全 | 认证与授权 | 支持 SSO/OAuth2、细粒度 RBAC、数据脱敏 | P0 |
| 安全 | 数据保护 | 传输加密 HTTPS、存储加密、备份与恢复 | P0 |
| 合规 | 审计与留痕 | 关键操作可追溯、日志不可篡改策略 | P0 |
| 易用性 | 学习成本 | 业务管理员可在 1 天内独立搭建简单表单 | P1 |
| 可维护性 | 配置优先 | 80% 以上需求通过配置满足，减少定制开发 | P1 |
| 可扩展性 | 插件化能力 | 字段组件、图表、打印渲染支持扩展点 | P1 |

## 六、里程碑建议（二维表）
| 阶段 | 范围 | 交付物 | 周期建议 |
|---|---|---|---|
| M1：MVP | 表单编辑 + 填报 + 基础审批 + 基础打印 | 可上线试点版本 | 4-6 周 |
| M2：增强版 | 可视化报表 + 高级权限 + 审计日志 | 部门级推广版本 | 3-5 周 |
| M3：平台化 | 开放接口 + 模板中心 + 私有化支持 | 企业级版本 | 4-8 周 |

## 七、风险与待确认项（二维表）
| 类别 | 风险/问题 | 影响 | 建议 |
|---|---|---|---|
| 需求范围 | 初期范围过大导致延期 | 交付节奏失控 | 先冻结 MVP 范围，分期建设 |
| 规则复杂度 | 表单联动和流程过于复杂 | 维护成本上升 | 设定配置规范与命名标准 |
| 数据口径 | 报表口径不统一 | 决策偏差 | 建立指标字典与口径评审机制 |
| 权限策略 | 数据权限颗粒度不清 | 安全与合规风险 | 先定义最小权限模型 |
| 打印适配 | 多打印机/纸张兼容差 | 业务执行受阻 | 建立模板测试基线 |
| 集成对接 | 外部系统标准不一 | 实施周期不确定 | 提前确认接口协议与联调计划 |
