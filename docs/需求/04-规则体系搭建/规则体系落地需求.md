## 1. 阶段目标与范围（二维表）
| 维度 | 内容 | 说明 |
|---|---|---|
| 阶段目标 | 将规则体系拆解为可投入开发的产品与研发需求 | 覆盖交互规则引擎和业务规则引擎的编辑态与运行态 |
| 面向角色 | 业务管理员、实施人员、前端研发、后端研发、测试人员 | 管理员负责编排规则，研发负责执行引擎落地 |

## 2. 三期功能总览（二维表）
| 模块 | 子功能 | 需求描述 | 验收标准 | 优先级 |
|---|---|---|---|---|
| 编辑态 | 交互规则编排 | 提供前端交互规则的可视化编排能力 | 可创建、编辑、发布交互规则流程 | P0 |
| 编辑态 | 业务规则编排 | 提供服务端业务规则的可视化编排能力 | 可创建、编辑、发布业务规则流程 | P0 |
| 运行态 | 前端规则运行时 | 在当前表单运行交互规则流程 | 规则按触发器与执行单元顺序稳定执行 | P0 |
| 运行态 | 后端规则运行时 | 在服务端运行事务型业务规则流程 | 规则按事件与处理器链顺序稳定执行 | P0 |
| 治理能力 | 规则发布与版本管理 | 规则支持草稿、发布、停用、回滚 | 可按版本回溯规则配置与执行结果 | P0 |
| 治理能力 | 调试与观测 | 提供规则执行日志、调试视图、错误定位 | 可按规则ID和请求ID追踪问题 | P0 |

| 主要配置内容 | 触发事件、执行单元、目标组件、失败策略 | 业务事件、处理器链、事务策略、补偿策略 |
| 生效边界 | 当前表单运行时 | 服务端事务运行时 |

## 4. 编辑态：交互规则编排需求（二维表）
| 需求项 | 需求描述 | 配置方式 | 验收标准 |
|---|---|---|---|
| 入口与导航 | 在表单编辑器中新增“交互规则”入口，支持按表单版本配置规则 | 工具栏入口或侧边栏入口进入规则编排页面 | 管理员可从当前表单直接进入交互规则编排 |
| 规则列表 | 展示当前表单下所有交互规则，支持搜索、复制、删除、启停 | 列表页管理 | 可按规则名称、触发器、状态筛选 |
| 新建规则 | 支持从空白新建规则，也支持从模板创建 | 点击“新建规则”后进入编排画布 | 可创建草稿规则并自动生成规则ID |
| 触发器配置 | 支持页面生命周期、字段值变化、用户动作、明细行为、提交流程等触发器 | 触发器面板选择事件与目标组件 | 可配置并保存触发源、触发条件、触发范围 |
| 流程画布 | 规则采用流程编排式画布呈现，按顺序展示执行单元链 | 画布节点编排，支持拖拽排序 | 规则流程结构清晰可视，顺序可调整 |
| 执行单元配置 | 支持为每个节点配置查询、判断、转换、操作、写上下文、反馈等执行单元 | 右侧属性面板配置节点参数 | 节点配置可保存、回显、校验 |
| 节点类型清单 | 首批支持查询类、判断类、转换类、操作类、写上下文类、反馈类节点 | 节点库拖入画布 | 节点类型与文档定义保持一致 |
| 条件分支 | 支持在流程中增加条件判断与分支节点 | 画布中增加“条件节点” | 条件命中后可进入不同分支 |
| 失败策略 | 支持中断、跳过、继续执行、提示用户等失败策略 | 在规则级或节点级配置 | 执行失败时符合预期策略 |
| 目标组件选择 | 执行单元操作目标需可从当前表单组件树中选择 | 组件树选择器 | 仅可选择当前表单允许作用的组件 |
| 发布前校验 | 校验触发器、节点参数、组件引用、流程连线合法性 | 点击发布时执行 | 非法流程无法发布并给出定位信息 |

## 6. 编辑态：业务规则编排需求（二维表）
| 需求项 | 需求描述 | 配置方式 | 验收标准 |
|---|---|---|---|
| 入口与导航 | 在规则中心或表单管理后台新增“业务规则”入口 | 独立规则中心或表单下业务规则页 | 管理员可进入服务端规则编排页面 |
| 规则列表 | 展示业务规则列表，支持按业务域、事件类型、状态筛选 | 列表页管理 | 可快速定位规则 |
| 新建规则 | 支持按事件类型新建业务规则，如“单据提交”“状态变更” | 新建向导 + 画布 | 新建后自动生成规则编码 |
| 事件配置 | 支持单据提交、状态变更、系统回调、定时补偿等事件入口 | 事件面板配置事件类型和作用域 | 规则能绑定到具体业务事件 |
| 流程画布 | 业务规则采用流程编排式画布呈现，节点按处理器链顺序排列 | 画布拖拽节点编排 | 流程顺序、分支和补偿链可视化 |
| 规则处理器配置 | 支持查询、校验、裁决、锁定、写入、状态推进、补偿、通知等处理器 | 节点属性面板配置参数 | 处理器参数可保存和回显 |
| 事务策略配置 | 规则级支持事务边界、幂等键来源、锁策略、补偿策略配置 | 规则基础配置区域 | 可定义事务模式和一致性策略 |
| 补偿链配置 | 支持为写入类或资源类处理器配置补偿节点 | 在节点下挂补偿处理器 | 主流程失败时可触发补偿链 |
| 发布前校验 | 校验事件合法性、处理器参数、幂等配置、补偿完整性 | 点击发布时执行 | 非法规则不能发布 |
| 灰度与版本 | 支持草稿、发布、停用、回滚及按业务域灰度生效 | 规则发布控制台 | 不同版本可独立生效和回溯 |

## 10. 运行态：前端运行需求（二维表）
| 需求项 | 需求描述 | 验收标准 |
|---|---|---|
| 规则加载 | 页面进入时加载当前表单已发布的交互规则配置 | 规则可按表单版本正确加载 |
| 事件捕获 | 捕获页面生命周期、字段变化、明细行为、用户动作等事件 | 触发器命中准确 |
| 上下文构建 | 在规则执行前构建页面、组件、数据、用户、临时变量上下文 | 执行单元可正确读取上下文 |
| 流程执行 | 按规则流程顺序执行节点，支持分支和失败策略 | 顺序、条件、失败策略符合配置 |
| 组件命令分发 | 将操作类节点结果分发给目标组件 | 组件响应准确、状态同步 |
| 局部刷新 | 规则执行后局部更新页面状态，避免整页重渲染 | 常规场景下交互延迟可控 |
| 错误处理 | 执行失败时按规则配置中断、跳过、提示或继续 | 错误行为可预测且可定位 |
| 调试日志 | 前端记录规则执行轨迹、输入输出、错误信息 | 可按规则ID查看日志 |

## 11. 运行态：后端运行需求（二维表）
| 需求项 | 需求描述 | 验收标准 |
|---|---|---|
| 事件接入 | 接收提交、状态变更、回调、定时补偿等业务事件 | 事件能正确路由到规则运行时 |
| 幂等校验 | 在执行规则前校验幂等键，防重复处理 | 重复请求不重复生效 |
| 事务上下文构建 | 构建业务单据、资源、规则、补偿、审计上下文 | 处理器可正确读取上下文 |
| 流程执行 | 按规则流程顺序执行处理器链，支持分支和补偿 | 主流程、分支、补偿链按配置执行 |
| 资源锁定 | 对库存、预算等关键资源加锁或预占 | 并发场景下资源不超扣 |
| 数据写入与状态推进 | 执行跨表单写入、生成下游单据、推进状态 | 事务成功时数据一致 |
| 补偿回滚 | 任一关键步骤失败时触发补偿或回滚 | 失败后不留脏数据 |
| 执行日志 | 记录规则命中、处理器链、耗时、补偿和最终结果 | 可按请求ID和规则ID检索 |

## 12. 编辑态与运行态数据约束（二维表）
| 约束项 | 需求描述 | 验收标准 |
|---|---|---|
| 规则版本隔离 | 编辑态草稿与运行态发布版隔离 | 未发布规则不进入运行态 |
| 配置结构统一 | 编辑态保存结构与运行态执行结构一致 | 前后端执行不依赖二次手工转换 |
| 引用校验 | 规则引用的组件、字段、表单、资源必须合法存在 | 删除被引用对象时提示风险 |
| 执行结果回传 | 后端执行后需返回最终结果供前端刷新 | 提交结果与最终状态一致 |

## 13. 发布与治理需求（二维表）
| 能力 | 需求描述 | 验收标准 |
|---|---|---|

## 15. 风险与对策（二维表）
| 风险 | 影响 | 对策 |
|---|---|---|
| 编辑态过重 | 管理员难以上手 | 首期控制节点数量，提供模板与分层入口 |
| 交互规则与业务规则边界模糊 | 前后端职责混乱 | 入口、术语、作用范围明确分开 |
| 运行态性能不足 | 表单体验差或事务执行慢 | 前端局部刷新、后端分层处理、关键链路监控 |
| 规则调试困难 | 问题定位成本高 | 提供模拟执行、单步调试、请求级日志 |
